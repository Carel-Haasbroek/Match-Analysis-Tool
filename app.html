Help and instructions

Starting a session

+ New session on the home screen takes a YouTube link or a video file from this machine. Tick Only part of this video and give a start and an end to work on one passage — marks are then timed from the start of that segment, so 0:00 is where it begins.

You can also drag a video file straight onto the player.

A session is one video and everything you have written about it. Opening the same video again always reopens the same session: local files are recognised by their name and size, so it does not matter where the file sits on disk.

Marking a moment

Pause where you want, click Mark this moment, draw on the frame with the pen, arrow or box, type a note if you want one, and save. The drawing is pinned to that timestamp.

While you watch

Each drawing reappears as playback reaches its moment and clears again shortly after. The Hold slider under the video sets how long, from a flash to two seconds. The note's text shows across the bottom of the picture; the chevron collapses it, and reaching the next note opens it again.

Pause at notes stops playback on every marked moment, which is the quickest way to walk through a match you have already been through once.

Several coaches on one video

Every moment holds a thread rather than one line. The box under a moment in the notes panel adds another comment, and each is signed with the name you set under Who is commenting. Two coaches can disagree about the same tackle and you can see who said what.

Finding things again

The home screen lists what you opened recently. All sessions in the top bar opens the lot, with a search box and your folders drawn as a tree.

New folder… makes one, and a name with a / in it nests. Hovering a folder shows a pencil to rename it and, when it is empty, a cross to remove it — a folder with sessions in it cannot be removed, so this is never a way to lose notes. Drag a session onto a folder to move it there, or use the dropdown on its row. Either way the folder moves on disk too, so what you see here is what you see in Explorer.

Vaults

A vault is a folder your notes live in, and all of your vaults are used at once. Sessions from every vault appear in the same list; the only difference between them is which one new sessions go into, marked new notes.

To share with other coaches, put a vault inside Google Drive, Dropbox or OneDrive and have each coach add that same folder as a vault on their own machine, under Preferences → Vaults. Each app writes its own file inside a session, so nobody overwrites anybody, and everyone's notes are merged when a session is opened. Removing a vault only forgets it — the folder and everything in it stays exactly where it is.

Dragging a session onto a different vault in the tree moves it there for good, taking every coach's notes with it. It asks first, and refuses if that vault already has the same session — combining two copies is what Export and Import is for.

Keeping a copy

Export all notes writes one file holding every note, comment, summary and session name. Import backup merges one back in: it only ever adds, so restoring an old backup cannot cost you newer work. That is also how you hand a whole set of notes to somebody who is not sharing a vault.

Open shared clip loads a clip file somebody sent you, and Make clip under the video creates one from an in and an out mark.
